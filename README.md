## O projekcie

CVGo — Generator CV zbudowany przy użyciu Next.js i Tailwind CSS. Repozytorium zawiera front-end: komponenty, układ i przykładowe szablony.

## Live Demo: ...

## Stack technologiczny

- Framework: Next.js (App Router)
- Język: TypeScript
- Stylowanie: Tailwind CSS
- Ikony / UI: `lucide-react`, `@headlessui/react`

---

## Uruchomienie projektu lokalnie

1. Zainstaluj zależności i uruchom lokalny serwer deweloperski:

```bash
git clone https://github.com/alvvik/CVGo.git
cd CVGo
npm install
npm run dev
```

2. Otwórz w przeglądarce: `http://localhost:2877` .
